# Datasets

This project uses two datasets for the KNN and Naive Bayes experiments.

## Credit Card Fraud Detection

The credit card dataset is included in this folder as:

`creditcard.csv`

## Online Retail II

The Online Retail II dataset is not included in this repository because the Excel file exceeds GitHub's browser upload size limit.

Download the dataset and place it in this folder using the following filename:

`online_retail_II.xlsx`

The notebooks use the following path:

`../dataset/online_retail_II.xlsx`

After adding the file, the expected structure is:

```text
dataset/
├── creditcard.csv
└── online_retail_II.xlsx
```
